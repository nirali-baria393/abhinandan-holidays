# Abhinandan Holidays

Travel website for Abhinandan Holidays, built with React, TypeScript and Vite.

## Run locally

    npm install
    npm run dev

## Build

    npm run build

Output goes to `dist/`. Deploy settings for Netlify are in `netlify.toml`.

## Editing content

Destinations, activities, themes and reviews live in `src/data/site.ts`.
The reviews there are placeholders and must be replaced with real customer reviews before launch.
